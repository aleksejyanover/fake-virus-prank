# 🦠 Пранк «Фейковый вирус»

Безопасный пранк-симулятор вируса: страшные окна, **фейковое удаление файлов** (ничего настоящего не трогается), отчёт об удалении, скример, синий экран — а в конце всё «восстановление» и **освобождение компьютера**.

> ⚠️ Приложение **ничего не удаляет и не изменяет** на компьютере. Все «удалённые» файлы — только картинка на экране. В конце жертва узнаёт, что это была шутка.

## 🔗 Где это работает

| Версия | Как открыть |
|---|---|
| 🌐 Веб | Ссылка на GitHub Pages (см. ниже) |
| 🪟 Windows | Двойной клик по `Запуск для Windows.bat` (откроется полноэкранно в Edge/Chrome) |
| 🍎 macOS | Двойной клик по `Фейковый вирус.app` в Finder |
| ⚙️ Настройка действий | `editor.html` — сайт, где добавляешь действия по времени и скример |

## 🎛 Редактор действий (editor.html)

Открой редактор и настрой сценарий:

- **Действия по времени** — когда и что произойдёт (в секундах от старта);
- **Типы действий**: сообщение/окно, фейковое удаление, отчёт об удалении, скример (перепуг), синий экран, восстановление, финал «контроль освобождён»;
- **Готовые сценарии**: ⚡ Быстрый (~45 сек), 👾 Классический (~75 сек), ⏳ Долгий (~95 сек);
- **▶ Запустить пранк** — открыть сразу;
- **🔗 Скопировать ссылку** — в ссылку зашиты настройки, можно отправить другу;
- **💾 Скачать файл пранка** — отдаёт `index.html` с твоими настройками, работает офлайн.

## ▶ Запуск

1. **Веб**: открой `index.html` (или ссылку с настройками) → **«Начать проверку»** → пойдёт сценарий.
2. **Windows**: `Запуск для Windows.bat` открывает пранк полноэкранно (kiosk-режим Edge/Chrome).
3. **macOS**: `Фейковый вирус.app` открывает пранк в браузере; если не встало полноэкранное — `Cmd+Ctrl+F`.

**Esc** — выйти из полноэкранного режима. В конце показывается спокойный экран «Проверка завершена — система в порядке» (без разгадки «пранк»).

## 🔒 Защита от случайного закрытия

- Попытка закрыть/обновить вкладку во время сценария — браузер спросит подтверждение;
- Крестик «✕» в окнах не закрывает их — окно дрожит и играет звук ошибки;
- Правая кнопка мыши отключена на время сценария;
- В kiosk-режиме (`.bat` / `.app`) панель вкладок вообще не видна;
- Внимание: Esc и Alt+F4 — системные клавиши браузера, их заблокировать нельзя (и не нужно: застрять навсегда никто не должен).

## 🛡 Безопасность

- Никакого доступа к файлам — пранк работает в браузере, он физически не может ничего удалить.
- Никаких аккаунтов, паролей, сети — только картинка, анимация и звук (WebAudio, без файлов).
- В конце показывается честное раскрытие: «это была шутка, файлы на месте».
- Сделано для шуток между друзьями. Не используй, чтобы довести человека до паники.

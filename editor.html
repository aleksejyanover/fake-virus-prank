🎛 Редактор пранка «Фейковый вирус»

Настрой, что и когда будет происходить: сообщения, фейковое удаление файлов, скример, синий экран, восстановление и «освобождение компьютера». Ничего настоящего не удаляется — это безопасный пранк.

⚙️ Общие настройки

▶ Запустить — откроет пранк в новой вкладке (Esc — выйти из полноэкранного режима).
🔗 Ссылка — в неё зашиты твои настройки: можно отправить другу, откроется с этим же сценарием.
💾 Скачать — отдаст файл index.html уже с твоими настройками; работает двойным кликом даже без интернета.

⏱ Действия по времени

Время — через сколько секунд после запуска произойдёт действие. Стрелки ↑↓ меняют порядок (сортировка идёт по времени), ✕ удаляет.
